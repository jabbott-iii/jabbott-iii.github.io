# [Munus v2.0 — Export and Import Functionality Added!!!](https://github.com/jabbott-iii/Munus)

## TUI changes:

The TUI (text-based user interface, the interactive view inside the terminal) can now export and import tasks.

<img width="574" height="270" alt="Munus terminal UI Import Tasks dialog with an empty path field and toggles for merge mode, backup before import, and strict parsing" src="https://github.com/user-attachments/assets/e259a85a-0898-4933-85cc-d4a096caf3c7" />

## CLI changes:
All commands have been moved to the Cobra framework (a Go library for building CLI apps) to facilitate a better experience. Try `munus -h` to get started!
