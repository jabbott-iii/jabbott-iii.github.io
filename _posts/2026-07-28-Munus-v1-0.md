# [Munus v1.0 — First Stable Release](https://github.com/jabbott-iii/Munus)

I am excited to announce the first stable release of **Munus**, a task-managing TUI/CLI tool built for the terminal-first workflow. (A TUI, or text-based user interface, is an interactive app drawn inside the terminal.)

Munus v1.0 marks the project’s initial major milestone and introduces a clean, lightweight way to manage tasks from the command line. Designed in Go and distributed as native binaries for Linux, macOS, and Windows, Munus aims to make task tracking fast, simple, and always available where you work.

## What’s in v1.0

- First stable public release
- Terminal-based task management application using both a TUI and CLI commands
- Cross-platform binaries for:
  - Linux x86_64
  - Linux arm64
  - macOS x86_64
  - macOS arm64
  - Windows x86_64
  - Windows arm64
- Detailed installation and usage instructions
- Apache 2.0 licensed

## Roadmap

v1.0 lays the foundation for future improvements. I am currently focused on building peer-to-peer database sharing (sharing the task database directly between machines, with no central server) and the final CLI commands that are missing.
