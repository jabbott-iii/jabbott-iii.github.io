{%- comment -%} Decorative backdrop behind every page: star fields and a grid, bronze circuit traces on the left, and a purple network of nerve cells (synapses) on the right. Every few seconds a spark runs along a trace or from cell to cell. The sparks are SVG (a transform) and opacity changes, so they need no JavaScript; CSS hides them for reduced motion. Each drawing is 400 × 1000 viewBox units. A pulse is a path with an id (the route), a glow where it lands, and a spark whose follows that path; its begin list ("2s;sa3m.end+8s") sets the first start and the pause before it repeats. {%- endcomment -%}
