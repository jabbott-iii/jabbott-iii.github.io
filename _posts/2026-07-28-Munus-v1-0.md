# [Munus v1.0 — First Stable Release](https://github.com/jabbott-iii/Munus)

I am excited to announce the first stable release of **Munus**, a task-managing TUI/CLI tool built for the terminal-first workflow.

Munus v1.0 marks the project’s initial major milestone and introduces a clean, lightweight way to manage tasks from the command line. Designed in Go and distributed as native binaries for Linux, macOS, and Windows, Munus aims to make task tracking fast, simple, and always available where you work.

## What’s in v1.0

- First stable public release
- Terminal-based task management experience
- Cross-platform binaries for:
  - Linux x86_64
  - Linux arm64
  - macOS x86_64
  - macOS arm64
  - Windows x86_64
  - Windows arm64
- Simple installation and usage flow
- Apache 2.0 licensed

## Why Munus?

Munus is for users who want a fast, focused task manager that lives in the terminal. It’s ideal for developers and power users who prefer keyboard-driven workflows and minimal distractions.

## Looking ahead

v1.0 lays the foundation for future improvements. Expect ongoing enhancements, refinements, and additional functionality as Munus continues to grow.
